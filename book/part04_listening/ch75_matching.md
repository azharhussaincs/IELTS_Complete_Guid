## Learning Objectives

By the end of this chapter, you will be able to:

- Distinguish matching people/opinions, features, dates, and categories across Listening sections.
- Apply "each letter may be used once only" rules without duplication errors.
- Track multiple speakers in Section 3 matching tasks using voice and role cues.
- Handle matching when option order differs from audio order (non-linear matching).
- Use elimination grids to narrow remaining options efficiently.
- Match long option lists (A–F, A–H) under time pressure without losing audio sync.
- Recognise when speakers change positions mid-discussion and update matches accordingly.

## Theory / Explanation

### 75.1 What Is Matching in Listening?

Matching tasks require you to **pair items from two lists**:

| List 1 | List 2 |
|--------|--------|
| Questions 21–25 (people, places, events) | Options A–H (opinions, features, dates) |

You write the **correct letter** (usually) on the answer sheet. Variations include matching **course modules to descriptions**, **museum exhibits to themes**, or **research stages to actions**.

### 75.2 Core Rule: Used Once?

Instructions state:

- *"Each letter may be used **once only**."* — standard; elimination powerful.
- *"You may use any letter **more than once**."* — rare; read carefully.

**Most IELTS matching = once only.** Cross off assigned letters in preview margin.

### 75.3 Linear vs Non-Linear Order

**Linear:** Audio discusses Item 1, then Item 2 — matches question order.

**Non-linear:** Audio jumps — e.g., Speaker A discussed, then C, then B. **Questions still numbered 21–25 in fixed order** — you match as evidence appears.

**Strategy:** Maintain **grid**:

| Person | A | B | C | D | E |
|--------|---|---|---|---|---|
| Maya | | ? | | | |
| Jonas | | | | | |

Fill when confident; leave blank until speaker returns.

### 75.4 Section 3: People and Opinions

Classic format: three students + tutor discuss project; match each person to opinion or contribution.

**Speaker identification cues:**

| Cue | Function |
|-----|----------|
| Name at turn start | "Maya, what do you think?" |
| Voice change | Distinct pitch/pace |
| Role language | "As your tutor, I'd say…" |
| Agreement | "I agree with Jonas" links opinion |

**Practice:** Podcasts with named hosts build speaker tracking.

### 75.5 Matching Features to Categories

Example: Match wildlife species (questions) to habitats (options A–F).

Audio may describe species **in random order**. Each species mentioned once; habitat option used once.

**Anchor on **unique detail**:** *"The sandpiper nests only on shingle banks"* → match shingle option.

### 75.6 Date and Event Matching

Timeline matching tests:

- **Chronology words:** initially, subsequently, finally
- **Date traps:** two events same month — listen for day or sequence

Write letter of event description, not the date itself, unless question asks for date completion separately.

### 75.7 Long Option Lists (A–H)

With 8 options and 5 questions, **3 distractors** never used — useful sanity check at end.

If 6 letters used for 5 questions under "once only" — error detected; review.

### 75.8 Paraphrase in Matching

Options rarely copy audio:

| Audio | Option |
|-------|--------|
| "worried about funding" | B financial constraints |
| "keen to expand sample" | D increase participants |

Build **concept bridges** in preview.

### 75.9 Combined Matching + Other Types

A section may blend matching with MCQ or completion. **Read instruction boundaries** — where matching ends, completion begins.

### 75.10 Common Errors

| Error | Fix |
|-------|-----|
| Duplicate letter | Cross-off rule |
| Wrong speaker | Name tally each turn |
| Early commit | Wait for correction |
| Distractor mention | Match main clause |
| Skim options too late | Preview all A–H before audio |

### 75.11 CDT and PBT Matching

PBT: write letter clearly in box.  
CDT: some interfaces drag-drop; practice official familiarisation test.

### 75.12 Progression Drill

1. **Static:** Match quotes to speakers on paper (reading) — build grid habit.  
2. **Audio drama:** BBC radio clips with 3 characters — note who said what.  
3. **IELTS timed:** full section one-play.

## Worked Examples

### Worked Example 1: Three Students

**Match concern to person:**

| Option | Concern |
|--------|---------|
| A Sample size | |
| B Time limit | |
| C Equipment failure | |
| D Location access | |

**Audio:**
- **Priya:** *"We only had twelve respondents."* → **A**
- **Sam:** *"The spectrometer broke twice."* → **C**
- **Priya later:** *"Also, the site warden delayed our entry."* → **D** for Priya's second concern? **Question structure matters** — if one concern per person only, first Priya answer locks A; warden issue may be separate question.

**Lesson:** Read whether **one match per person** or **multiple items per person**.

### Worked Example 2: Exhibit Matching

**Exhibits 11–14:** Pottery, Textiles, Coins, Manuscripts  
**Themes A–F:** Trade routes, Domestic life, Royal court, Religious ritual, Warfare, Agriculture  

**Audio:** *"The coin hoard mainly illustrates long-distance **trade**, whereas the pottery fragments reflect everyday **household** activity."*

Matches: Coins→Trade (A), Pottery→Domestic (B).

### Worked Example 3: Elimination

Five questions, options A–F. After four matches, one question remains with two plausible unused letters — re-listen mentally to audio memory; if tied, choose option with **stronger paraphrase match**, not keyword.

## Practice Exercises

### Practice 1 — Section 3 Project Discussion

**Match each person to their primary recommendation (A–E). Each letter once.**

**Options:**  
A Extend deadline  
B Change methodology  
C Reduce scope  
D Seek external funding  
E Publish early  

**Transcript (original):**

> **Tutor:** Recommendations?  
> **Elena:** We're **running out of time** — I'd ask for an **extension**.  
> **Marcus:** I think we should **narrow the research question** — too broad now.  
> **Elena:** Funding could help us hire an assistant — actually **external grant** might work.  
> **Tutor:** Marcus, still prefer scope reduction?  
> **Marcus:** Yes, **cut the secondary survey**.  
> **Tutor:** I'll **publish preliminary findings** on the department blog.  
> **Elena:** Good — **early visibility** helps recruitment.

**Questions:**  
1. Elena (primary)  
2. Marcus  
3. Tutor  

*Note: If one recommendation each, Elena's PRIMARY is extension A; funding mention secondary.*

### Practice 2 — Festival Events

**Match event to day (A–F).**

**Options:** A Friday, B Saturday am, C Saturday pm, D Sunday am, E Sunday pm, F Monday

**Transcript (original):**

> The **folk concert** opens the festival **Friday evening**. **Craft workshops** run **Saturday morning** only. The **fireworks** display is **Saturday night**. **Food fair** continues all **Sunday**. **Parade** closes the event **Monday midday**.

### Practice 3 — Research Methods

**Match study to limitation heard (A–D).**

A Small sample  
B Cultural bias  
C Outdated data  
D Measurement error  

**Transcript (original):**

> Study one on teen sleep used only **forty participants**. Study two on diet compared **1990s records** to today. Study three on posture relied on **self-report questionnaires**. Study four on noise used ** miscalibrated microphones** initially.

### Practice 4 — Hotel Facilities (A–H)

Match room type to feature described.

**Transcript (original):**

> **Deluxe rooms** face the **harbour** and include **breakfast**. **Standard rooms** overlook the **car park** but have **kettle facilities**. **Suites** add a **sofa bed** and **evening turn-down service**. **Family rooms** provide ** bunk beds** and **playstation console**.

**Speakers:** Anna, Ben, Cara

**Transcript order:** Ben (budget), Cara (marketing), Anna (transport), Cara (budget comment — agree), Ben (accommodation)

## Review

- Matching = **grid + cross-off** letters.
- Order may **not** follow questions — patience.
- Section 3: **identify speakers** reliably.
- Paraphrase bridges lists.
- Verify **once-only** rule at end.
- Unused options often expected — sanity check.

## Exam Tips

> **Exam Strategy:** Write **tiny cross** next to used letters the moment you commit — prevents duplicate assignment under stress.

> **Exam Strategy:** If two speakers agree, **both may map to similar options** — read whether questions ask for shared or individual views.

> **Exam Strategy:** Don't match on **one word** — wait for full opinion clause.

## Band 9 Tips

> **Band 9 Secret:** Band 9 matchers **assign provisional letters in pencil** and adjust only on explicit correction — avoids erasure panic.

> **Band 9 Secret:** They preview **distractor options** knowing three will never appear — accelerates late-section elimination.

> **Band 9 Secret:** Speaker maps include **role tags** (T=tutor) before audio — one glance resolves turn-taking ambiguity.

## Extended Theory — Voice Identification Drills

When names are infrequent, track:

| Speaker | Pitch | Speed | Role vocabulary |
|---------|-------|-------|-----------------|
| Student A | higher | fast | "I think", "maybe" |
| Student B | lower | slow | "data shows" |
| Tutor | measured | deliberate | "you should", "the criteria" |

Practice with BBC drama clips: pause every 30 seconds — note who spoke last line. **Why this matters:** Section 3 matching without reliable speaker ID forces guesswork on opinion questions.

## Extended Practice Set G — Historical Events Timeline

**Match event (11–14) to century (A–F).**

A 15th century | B 16th century | C 17th century | D 18th century | E 19th century | F 20th century

**Transcript (original):**

> The **printing press** reached England in the **late fifteenth century**. **Industrial textile mills** expanded rapidly in the **early nineteenth**. The **scientific revolution** peaked in the **seventeenth**. **Railway networks** dominated **Victorian** Britain — **nineteenth century** again, but **later** than textiles' initial phase. **Digital archives** emerged in the **twentieth**.

**Solutions:** printing-A | textiles-E (early 19th) | scientific revolution-C | railways-E (later 19th — if one letter once, distinguish by question: "railway dominance" vs "textile mills" may both be E — exam would separate sub-periods or use different option sets) | digital-F — **Note:** Real IELTS avoids ambiguous double-E; pedagogical point: **time qualifier** ("early"/"late") disambiguates.

## Appendix 75.C — Matching vs Classification

**Matching:** pair two lists of equal conceptual level (person ↔ opinion).  
**Classification:** assign items to categories (species ↔ habitat).

Same grid technique applies; classification often has **more options than questions** — elimination identical.
