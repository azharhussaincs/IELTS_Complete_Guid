## Learning Objectives

By the end of this chapter, you will be able to:

- Complete sentence gaps with grammatically correct words drawn from the recording.
- Handle summary paragraphs with and without optional word boxes.
- Apply word limits while preserving grammatical fit (singular/plural, verb form).
- Use surrounding sentence syntax to predict missing word class before listening.
- Track paraphrased summaries in Section 4 where gaps condense entire clauses.
- Distinguish sentence completion from note completion regarding grammar requirements.
- Avoid inserting words that fit meaning but break grammar or exceed limits.

## Theory / Explanation

### 76.1 Task Variants

| Variant | Description | Common section |
|---------|-------------|----------------|
| Sentence completion | Single sentences with one gap each | 2–4 |
| Summary completion | Connected paragraph with multiple gaps | 3–4 |
| Summary with word box | Choose from provided list (may include distractors) | 4 |

All require **exact words from recording** unless word box supplies fixed spelling.

### 76.2 Grammar-Sensitive Gap Filling

Unlike some note completion, **sentence completion gaps must produce grammatical sentences** when filled.

**Preview technique:** Cover the gap mentally; read before + after:

| Frame | Gap type |
|-------|----------|
| `The ___ was measured in metres.` | Noun |
| `Researchers were surprised by the ___.` | Noun phrase head |
| `This process occurs more ___ in winter.` | Adverb |
| `The chemical can ___ water quality.` | Verb (base) |

**Why grammar matters:** IELTS sometimes accepts only **singular** if article is *a*; plural if *many*.

### 76.3 Word Limits and Inflection

Instructions: typically ONE WORD ONLY or TWO WORDS AND/OR A NUMBER.

- **Plural -s** counts as part of word — *requirements* is one word.
- **Numbers** as digits or words per practice.
- Do **not** add articles unless gap is after verb and limit allows: *"became a leader"* — if limit ONE WORD → *leader* not *a leader* unless *a* printed in question.

### 76.4 Summary Completion Flow

Summary paraphrases lecture **out of order** occasionally — but **gaps usually follow audio order** within the summary block.

**Strategy:**
1. Read entire summary for **topic skeleton**.
2. Identify **co-reference** (*this process*, *the study*) linking sentences.
3. Listen for **synonym chains** connecting gap to audio.

### 76.5 Word Box Tasks

Box contains **more words than gaps** — unused words are distractors.

**Process:**
- Mark words that **cannot fit grammar** of any gap immediately.
- Assign high-confidence matches during first pass.
- Use elimination for remaining.

**Spelling:** Copy exactly from box — never alter box word form unless instruction allows transformation (rare in Listening — usually **exact box word**).

### 76.6 Paraphrase Density in Section 4

Example:

**Audio:** *"Photosynthesis enables plants to convert light energy into chemical form."*

**Summary gap:** Plants transform light into ___ energy.

**Answer:** **chemical** (ONE WORD) — extracts from paraphrase.

### 76.7 Synonym Prediction Table

| Question summary word | Possible audio words |
|-----------------------|----------------------|
| reduce | lower, decrease, cut |
| important | significant, crucial, key |
| fast | rapid, quickly (grammar!) |
| problem | challenge, difficulty, issue |
| show | demonstrate, indicate, reveal |

Build personal table from AWL (Chapter 69).

### 76.8 Trap Patterns

1. **Same root, wrong form:** *economy* heard but gap needs *economic*.
2. **Near synonym not accepted:** Rare — key follows official answer; practice materials teach acceptable paraphrase tolerance.
3. **Over-writing:** Adding adjective when limit one word.
4. **Off-topic word** from later paragraph — misaligned question number.

### 76.9 Handwriting and Articles on Answer Sheet

Illegible letters cost marks. If unsure between *affect/effect*, context + grammar decide.

### 76.10 Integration with Reading Skills

Summary completion resembles **Reading gap fill** but **one play only**. Reading scan returns; Listening demands **real-time capture**.

Transfer skills: grammar prediction, word class, collocation awareness.

### 76.11 Section 3 Sentence Completion

Dialogue may complete sentences about **project decisions** — still grammatical fit required.

Voices alternate; answer often in **final agreed statement**.

### 76.12 Review Before Transfer

Read completed sentences whisper-quiet:
- Does each sentence sound English?
- Any plural disagreement?
- Word limit respected each gap?

## Examples

### Example 1: ONE WORD ONLY

**Sentence:** The main pollutant came from ___________ waste.

**Audio:** *"Industrial discharge was identified as the primary source."*

**Answer:** **industrial** — *industrial waste* complete; *discharge* changes meaning.

### Example 2: Summary Box

**Box:** chemical, chemically, chemistry, chemist

**Gap:** Plants convert light into ___ energy.

**Answer:** **chemical** — adjective modifies *energy*; not *chemically* (adverb).

### Example 3: Two-Word Limit

**Sentence:** Traffic noise affects sleep ___________.

**Audio:** *"…affects sleep quality patterns."*

**Answer:** **quality patterns** (two words) OR if ONE WORD limit → **quality**.

## Worked Examples

### Worked Example 1: Grammar Lock

**Sentence:** The experiment was conducted in a controlled ___________.

**Audio:** *"…in a controlled environment chamber."*

Limit: ONE WORD → **environment** (not *chamber* alone if sentence needs *environment*; full phrase *environment chamber* = two words if allowed).

**Decision tree:** Read limit → extract minimal words preserving meaning.

### Worked Example 2: Section 4 Summary

**Summary:** Urban trees reduce the ___ island effect in cities.

**Audio:** *"…mitigate the heat island effect…"*

**Answer:** **heat** — *heat island effect* is fixed collocation; gap already has *island effect*.

### Worked Example 3: Distractor in Box

**Box:** funding, fund, funded, fundamental

**Gap:** The project lacked sufficient ___________.

**Answer:** **funding** — noun fits after *sufficient*; *fund* verb/noun ambiguity wrong slot.

## Solutions (with WHY)

### Practice 1
1. **railway** — former railway land  
2. **weekend** — weekend market (two words if limit allows: *weekend market*)  
3. **compost** — council provides free compost  
4. **private** — donated privately → private donations / privately (*private* if "donations" in question stem)

**Check limits:** If TWO WORDS: Q2 = **weekend market**, Q4 = **private donations**

### Practice 2
1. **landmark** — stated directly  
2. **experienced** — modifies adults  
3. **feeding** — feeding grounds collocation  
4. **stopover** — stopover habitats  

**WHY wrong:** *feeding* vs *feeding grounds* — ONE WORD gap forces **feeding** if "grounds" outside gap.

### Practice 3
**vertical** — adjective before *plane*; *vertically* ungrammatical

### Practice 4
**motivation** — dropped when rewards removed

### Practice 5
1. **fraction**  
2. **spin** — lower spin speeds  
3. **mandatory** — mandatory filter fittings → ONE WORD *mandatory* if gap before *filters*

- Section 4 summaries = dense paraphrase training ground.

## Exam Tips

> **Exam Strategy:** If audio gives **three-word phrase** but limit ONE, extract the **head noun** that carries core meaning.

> **Exam Strategy:** Word box tasks: assign **sure matches first** — reduces combo guess at end.

> **Exam Strategy:** Watch **singular/plural** verb agreement either side of gap — *The results are* → plural noun likely.

15. Structures contain ___________ carbonate

## Extended Theory — Summary vs Sentence Order

Occasionally summary paragraphs **reorder** lecture sequence for rhetorical cohesion. **Gaps still usually follow audio chronology within the summary block** — but if disoriented:

1. Anchor on **proper nouns** (Melbourne, Pteropod) — locate audio moment.  
2. Reset alignment rather than forcing sequential guess.  

**Band 8+ habit:** Note margin timestamp ticks: ✓ Q11 ✓ Q12 ? Q13 when uncertain — clarifies realignment point on transcript review.

## Appendix 76.B — Collocation Gaps in Summaries

Section 4 often tests **fixed phrases**:

| Partial gap | Complete collocation |
|-------------|---------------------|
| carbon ___ | footprint / emissions |
| food ___ | chain / security |
| climate ___ | change |
| random ___ | sample |
| statistical ___ | significance |

When preview shows adjective + gap + noun, predict **collocation middle** — audio may supply only the missing component (*significance* after *statistical*).
