## Learning Objectives

By the end of this chapter, you will be able to:

- Complete ten full original IELTS-style Listening sections (100 questions) under timed conditions.
- Apply question-type strategies from Chapters 71–78 across realistic section progressions.
- Self-mark using detailed answer keys with WHY explanations for every item.

- Identify personal weak sections by scoring each bank section separately.
- Use transcripts for post-test analysis without relying on them during first attempt.
- Build stamina for the full 40-question, 30-minute Listening marathon.

## How to Use This Practice Bank

### Recommended Protocol

1. **Attempt first** — one play only, no transcript, strict 30 minutes (+10 transfer if PBT).
2. **Mark** using Solutions section — record raw score /10 per section.
3. **Analyse** — tag errors: spelling (S), distractor (D), paraphrase (P), accent (A), pace (T).
4. **Replay** missed segments with transcript **once** — note paraphrase path.
5. **Retry** missed question types in isolation after 48 hours.

## Theory / Explanation

### 79.1 Why a Dedicated Practice Bank?

Chapters 71–78 taught **techniques**. This chapter supplies **volume** — the condition under which techniques become automatic. Research on skill acquisition (overlearning) shows that stable performance requires varied repetition beyond initial understanding.

### 79.2 Bank Structure

| Block | Sections | Context mix |
|-------|----------|-------------|
| Block 1 | 1A, 1B | Social forms & bookings |
| Block 2 | 2A, 2B | Monologue tours & facilities |
| Block 3 | 3A, 3B | Academic discussions |
| Block 4 | 4A, 4B | Lectures (science/society) |
| Block 5 | 5A, 5B | Mixed full tests (40 Q each) |

Each section = **10 questions** with **full transcript** and **explained key**.

### 79.3 Question-Type Distribution (Approximate)

Across 100 questions:

- Completion (form/note/table/sentence/summary): ~45%
- Multiple choice: ~25%
- Matching: ~15%
- Map/plan/diagram: ~10%
- Short answer: ~5%

Mirrors official test balance.

### 79.4 Timing Guidance

Allow **~30 seconds preview per question** average across section — adjust by item density.

Section 4: front-load preview during Section 3 playback if your test centre permits booklet preview (policy varies — practice both).

### 79.5 Recording Your Own Audio (Optional)

Reading transcripts aloud with a partner simulates accent variety. Pause between question groups as in real tests.
