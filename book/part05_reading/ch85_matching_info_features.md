## Learning Objectives

By the end of this chapter, you will be able to:

- Distinguish matching information from matching features, matching sentence endings, and matching headings.
- Apply a systematic paragraph-indexing method for matching information questions.
- Match features (people, dates, theories, places) to statements using evidence-based confirmation.
- Handle questions that require scanning the full passage non-sequentially.
- Avoid the "first match" trap when multiple paragraphs mention the same keyword.
- Manage NB (nota bene) instructions when more than one answer may use the same letter.
- Complete matching sets efficiently by batching scans and using elimination.

## Theory / Explanation

### 85.1 Three Matching Subtypes

**Matching information** — Which paragraph contains the following information?  
Statements describe **facts, ideas, or findings**; answers are paragraph letters (A, B, C...).

**Matching features** — Match statements to a list of **named features** (researchers, countries, inventions, periods).  
Features may be used once only or more than once depending on instructions.

**Matching sentence endings** — First half of sentence given; choose correct ending from list.  
Tests grammar + meaning cohesion; usually **in order**.

**Why separate strategies:** Matching information scans **paragraphs as containers**; matching features scans **names as anchors**; sentence endings test **syntactic and semantic fit**.

### 85.2 Matching Information: Core Logic

**Question:** "Which paragraph mentions the role of fungi in nutrient cycling?"

**Method:**

1. **Index passage** during skim — one-line gist per paragraph in margin.
2. **Read statement** — underline 2–3 unique content words.
3. **Predict paraphrase** — nutrient cycling → decomposition, soil enrichment, organic matter breakdown.
4. **Scan paragraph index first** — narrow to 2–3 candidates.
5. **Intensive read** candidate paragraphs — confirm **specific information** present, not mere word overlap.
6. **Assign letter** — if two paragraphs qualify, NB rule may allow duplicate letters; if "each paragraph once only," pick best fit.

**Critical:** Statement must be ** substantively present**, not implied from unrelated content.

### 85.3 The First-Match Trap

**Scenario:** Three paragraphs mention "climate change." Only one discusses **insurance industry adaptation**.

**Trap:** First paragraph with "climate change" selected.  
**Fix:** Verify **full statement proposition** in intensive read.

**Verification question:** "Could I quote one sentence proving this statement?" If no → keep scanning.

### 85.4 NB (Nota Bene) Instructions

Many matching tasks state: **"You may use any letter more than once."**

**Implications:**

- Same paragraph letter may answer 2–3 questions.
- Do not eliminate a paragraph after one use.
- Conversely, some questions may share one paragraph — normal.

When **each letter once only** (rare in information matching): treat like headings — cross out used paragraphs.

### 85.5 Matching Features: People and Theories

**Format:** Box lists names (Dr. Reyes, Professor Tanaka, Wilson...) or categories (Theory A, Period 1...).

**Method:**

1. **Highlight all feature names** in passage on first read (circle in text).
2. **Annotate margin** — what is attributed to each person/theory.
3. **Match statement** to attributed content, not general topic.

**Trap:** Person mentioned in paragraph but statement describes colleague's view.

**Example:**

Passage: "Wilson disputed Tanaka's estimate."  
Statement: "Questioned a colleague's figures" → Wilson, not Tanaka.

### 85.6 Matching Sentence Endings

**Format:**  
Stem: "The primary obstacle to desalination expansion..."  
Endings: A. ...has been identified as energy consumption. B. ...was resolved in the 1990s.

**Method:**

1. **Read stem** — note grammar (what follows verb? noun phrase? clause?).
2. **Eliminate ungrammatical endings** — wrong part of speech, subject-verb disagreement.
3. **Scan passage** for paraphrase of completed sentence meaning.
4. **Test two finalists** — read full sentence aloud (silently) for cohesion.

**Order:** Usually follows passage order — use sequential positioning.

### 85.7 Non-Sequential Scanning Strategy

Matching information breaks passage-order convention. **Efficient approach:**

**Batch method:**  
Read statements 1–3. Scan entire passage once with all three in mind. Assign letters. Repeat for 4–6.

**Index method:**  
Build paragraph gist map upfront; match from map before deep scanning.

**Why batch:** Reduces full passage re-reads from 7 to 2–3.

### 85.8 Paragraph Gist Index Template

| Para | Gist (5–8 words) |
|------|------------------|
| A | Intro: wetland loss history |
| B | Planner scepticism, flood proof |
| C | Seoul stream restoration success |
| D | Developer vs conservation conflict |
| E | Economic cost-benefit analyses |

When statement arrives, match against **Gist column** first.

### 85.9 When No Paragraph Fits

Rarely, trick questions occur. If genuinely no match after full scan:

- Re-read NB instruction.
- Check paraphrase predictions — too literal?
- Flag and return — later questions may reveal structure.

**Do not force** — wrong letter loses mark; flagged return may clarify.

## Worked Examples

### Worked Example 1: Information Match with Paraphrase

**Statement:** "An example of monetary valuation applied over decades."

**Passage paragraph E:** "...cost-benefit analyses... when **thirty-year horizons** are applied."

**Paraphrase link:** monetary valuation = cost-benefit; decades = thirty-year horizons → **E**

### Worked Example 2: Feature Disambiguation

**Statement:** "Documented microbial activity in extreme cold."

**Passage:** Mensah led Arctic team; Tanaka replicated in Antarctica.

Both cold — read statements carefully: "extreme cold" + "documented" — Mensah's Arctic expedition first documented → **i. Dr. Mensah** if statement matches Arctic original discovery.

### Worked Example 3: Sentence Ending Selection

**Stem:** "Unlike earlier models, the revised simulation..."  
**Passage:** "...the revised simulation **incorporates feedback from ocean currents**."

**Ending G:** "...accounts for marine circulation patterns."  
Grammar: simulation accounts → fits. Meaning: ocean currents = marine circulation → **G**

## Exam Tips

1. **Build gist index during skim** — pays off for information matching.
2. **NB highlighted** — underline on question paper.
3. **Feature names:** annotate in passage margin on first encounter.
4. **Sentence endings:** read A+B as complete sentence before choosing.
5. **Don't match keyword only** — "economy" paragraph must match economic **detail** in statement.
6. **Two candidates?** Choose paragraph where detail is **central**, not passing mention.
7. **Roman vs letter** — check instruction format carefully.
8. **Return to flagged** information matches after reading whole passage.
9. **Grammar elimination** saves 30 seconds per sentence ending.
10. **Cross-module:** Listening matching (Chapter 75) uses similar elimination logic.

## Band 9 Strategies

1. **Pre-index during orientation pass** — Band 9 candidates never start information matching cold.

2. **Proposition quote test:** mentally cite half a sentence proving match — if impossible, reject paragraph.

3. **Feature timeline:** note chronological order of researchers — statements often follow narrative sequence even when questions don't.

4. **Sentence ending triage:** eliminate 2 endings on grammar in 5 seconds; use saved time on information matching.

5. **Dual-match awareness:** when NB applies, actively consider same paragraph for related statements — saves rescanning.

6. **Abstract statement decoding:** statements use higher abstraction than passage — decode before scanning.

7. **Paragraph border cases:** read last sentence of Para N and first of Para N+1 for split information.

8. **No forced distribution:** unlike some school tests, IELTS may use same letter 3 times — accept it.

9. **Integrate headings map:** if headings done first, gist index already exists — reuse.

10. **Error log tag:** "first-match" vs "paraphrase miss" vs "wrong feature attribution" — separate drills.

### 85.10 Sentence Endings: Advanced Grammar Filters

**Subject-verb agreement after blank:**

Stem: "The number of participants who completed..."  
Eliminate endings with plural verb if "number" is singular head.

**Relative clause continuity:**

Stem: "...researchers found that..."  
Ending must be complete clause (subject + verb), not noun phrase alone.

**Parallelism in lists:**

Stem: "...included reducing waste, improving efficiency, and..."  
Ending must be gerund phrase or parallel structure matching list.

### 85.11 Feature Matching with Dates and Periods

When features are **historical periods** (Early Medieval, Industrial Era):

- Timeline sketch in margin while reading.
- Statement may describe **event** — match period containing event, not period mentioned elsewhere.

**Example:** Statement: "Introduction of printing press." Period: Late fifteenth century — even if passage also mentions medieval manuscripts in earlier period.

### 85.12 Information Matching vs TFNG Overlap

Same fact may appear as:

- TFNG: "Printing spread rapidly in Germany."  
- Information match: "Reference to speed of printing diffusion."

**Difference:** TFNG evaluates truth; information match evaluates **location**. Use gist index for matching; use proposition compare for TFNG.

## Feature Matching: Theory vs Person vs Organisation

| Feature type | Scan for |
|--------------|----------|
| Researcher | verbs of discovery: found, argued, demonstrated |
| Organisation | policy actions: mandated, funded, banned |
| Theory/Model | named proper noun + definition clause |
| Historical period | dates bounding events |
| Place | proper noun + prepositional phrases |

Build attribution table while reading any feature-matching passage.

## Sentence Endings — Cohesion Checklist

Before selecting ending, verify:

- [ ] Subject-verb agreement  
- [ ] Tense consistency with stem  
- [ ] Pronoun reference clear  
- [ ] Preposition collocations natural  
- [ ] Meaning supported in passage  

Five checks in 15 seconds prevent impulsive wrong selections.
